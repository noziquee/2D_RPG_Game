## Controls
- **WASD** — move
- **Left mouse button** — sword attack toward the cursor
- **Space** — dash

The project now starts in `combat_test_arena.tscn` so the attack can be tested immediately. The goblin is a stationary test target, not the Phase 5 enemy AI.
